# Getting help

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/MoC-OSS/LOFT/discussions): how to use LOFT, how to design a manifest or a middleware, or an idea you want to talk through. Search first, as your question may already have an answer.

Before asking, check the [documentation](./docs/README.md) and the [examples](./examples/README.md).

## Bugs and feature requests

Open a [GitHub issue](https://github.com/MoC-OSS/LOFT/issues/new/choose) with the bug report or feature request form. For a bug, include the package versions and the smallest code that reproduces it.

The maintainers aim to triage new issues within 7 days. LOFT is maintained by a small team, so a fix or a feature may take longer; pull requests are welcome, see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Security problems

Do not use issues or discussions for them. Follow [SECURITY.md](./SECURITY.md).

## Paid services

LOFT and all its updates are free for everyone, with or without a paid contract. Help on GitHub does not depend on one.

Separately, [Master of Code Global](https://masterofcode.com), which maintains LOFT, offers optional paid services for teams that want more, such as development, integration and consulting. These services are a separate agreement and do not change the license or the support described above. To ask about them, use the [Master of Code contact page](https://masterofcode.com/contacts).
